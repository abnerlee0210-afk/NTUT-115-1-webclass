如何選擇適合自己的課程？

大學提供各式各樣的課程， 除了系上必修之外，也有許多選修與跨領域課程。 透過了解課程內容、評估自己的興趣， 可以讓學習更有目標。

選課前的注意事項

  1. 確認畢業學分： 先了解必修、選修與通識課程的學分要求。
  2. 評估課程負擔： 留意作業、考試、報告與專題的時間需求。
  3. 搭配個人興趣： 除了必修課，也可以選擇自己感興趣的領域。
  4. 安排自主學習： 保留課後複習與實作練習的時間。

實際選課規定請以各校教務處公告為準。 你也可以參考 國立臺北科技大學官方網站 取得學校相關資訊。
