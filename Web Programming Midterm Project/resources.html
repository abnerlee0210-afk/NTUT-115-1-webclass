找到適合自己的學習資源

提升學習效率的方法

1. 設定明確目標

將大型目標拆成較小的學習任務， 例如每天學習一個 CSS 屬性， 或每週完成一個簡單程式。

2. 理解後實際操作

閱讀教學文件之後， 嘗試自行修改範例程式， 觀察不同寫法產生的結果。

3. 整理學習筆記

記錄重要觀念、常見錯誤與解決方法， 方便日後複習及查詢。

4. 定期回顧進度

每週檢查自己的學習成果， 適時調整讀書計畫， 避免只追求進度而忽略理解。

網頁開發建議學習順序

如果你想從零開始學習網頁開發， 可以參考以下學習路線。

  1. HTML： 學習網頁結構、標題、段落、 清單、圖片、連結與表格。
  2. CSS： 學習顏色、字體、間距、 Flexbox 與版面設計。
  3. JavaScript： 學習變數、函式、事件處理， 以及 DOM 操作。
  4. 專案實作： 將學到的技術整合， 製作自己的互動式網站。
  5. GitHub Pages： 將網站發布到網路上， 讓其他人可以瀏覽。
